# Answer Bank Master Database Governance

## 현재 우선순위

프로젝트의 최우선 목표는 건강운동관리사 실기·구술 199문제 마스터 데이터베이스 구축이다. iOS 앱 기능 개발은 answer bank 검증·고도화보다 후순위다.

마스터 데이터베이스의 완료 조건은 199개 전 문제에 대해 문제 원문 검증, 모범답안, 실기 수행 순서, 구술 답변 순서, 핵심 키워드, 자주 틀리는 포인트, 암기 팁, 출처, 검증 상태 관리를 끝내는 것이다.

## 최우선 원칙

`시험 적합성 > 최신 학술성`

이 프로젝트는 운동생리학 최신 지식 데이터베이스가 아니라 건강운동관리사 실기·구술 합격 데이터베이스다. 답안은 최신 ACSM 기준보다 실제 건강운동관리사 채점자가 기대하는 답을 우선한다.

최신 기준과 기출 기준이 충돌하면 최신 기준을 무조건 정답으로 채택하지 않는다. 반드시 `reviewNotes`에 `기출 당시 기준 확인 필요`를 기록한다.

## 출처 우선순위

- Tier S: 건강운동관리사 공식 교재, 건강운동관리사 기출문제 해설, 건강운동관리사 실기·구술 강의자료, 건강운동관리사 수험서, 건강운동관리사 교육과정 자료
- Tier A: 국민체력100, PAPS, 대한체육회, 대한운동사협회, 국내 대학 운동처방 교재, 국내 학회 자료
- Tier B: ACSM, NSCA, AHA, CDC, WHO
- Tier C: 논문, PubMed, Physiopedia, Physiotutors
- Tier D: 블로그, 카페, 커뮤니티

Tier D는 참고만 허용한다. Tier D만 근거인 항목은 `sourceVerified: true`로 두지 않는다.

## 반복 루프

1. Pass 1: 문제 검토, 답안 초안 작성
2. Pass 2: 출처 대조
3. Pass 3: 답안 수정
4. Pass 4: 암기팁 보강
5. Pass 5: 시험 적합성 검토
6. Pass 6: 검증 상태 승격

추가 개선점이 더 이상 발견되지 않을 때까지 반복한다.

## answerStatus 규칙

`needs_review`

- 답안 부족
- 출처 부족
- 기준 충돌

`draft`

- 답안 존재
- 시험 답변 가능 수준

`verified`

- 답안 완성
- 시험 적합성 검토 완료
- 출처 검증 완료
- 기준 충돌 없음

## 검증 우선순위

1. 2025년 문제 24개
2. 반복 출제 영역: 위험군 분류, 혈압, 대사증후군, 저항성 트레이닝, 체력평가
3. 운동손상평가 및 재활
4. 잔여 문제

## verified 승격 조건

필수 조건:

- `modelAnswer` 존재
- `keyPoints` 3개 이상
- `commonMistakes` 존재
- `memoryTip` 존재
- `sourceRefs` 존재
- `sourceVerified: true`
- `reviewNotes` 정리 완료
- `needsReview: false`

추가 조건:

- 시험 적합성 검토 완료
- 기출 의도와 충돌 없음

혈압, 위험군 분류, PAR-Q, 운동처방 수치, 대사증후군처럼 연도에 따라 기준이 달라질 수 있는 문제는 기출 당시 기준과 최신 기준 차이를 `reviewNotes`에 기록한다. 기준 충돌이 남아 있으면 `verified`로 승격하지 않는다.

## Pass 보고 기준

매 Pass마다 다음을 보고한다.

- `verified` 수
- `draft` 수
- `needs_review` 수
- 신규 검증 수
- 수정 답안 수
- 충돌 발견 수
- 남은 검토 대상 수
